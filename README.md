# Hospital use among adults prescribed antidepressants in NHS Tayside

Companion website for a poster presented at the NHS Research Scotland Mental Health Network
Annual Scientific Meeting, Royal College of Physicians of Edinburgh, 22 October 2026.

Live site: https://nitram353.github.io/tayside-antidepressants/

Static site (HTML, CSS and vanilla JavaScript), hosted on GitHub Pages from the `main` branch.

- `index.html` – all content
- `css/style.css` – styles (poster palette: navy, white, orange)
- `js/app.js` – interactive rate-ratio heatmaps, figure lightbox and navigation
- `figures/` – manuscript figures (optimised PNGs)
- `assets/` – draft poster (PDF and PNG) and the QR code that links here
